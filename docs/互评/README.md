## 提了哪三条

1. **「36/36（100%）」缺分母定义**。报告头写 `调查覆盖：36/36（100%）`，但全文没说分母 36 从哪来。按编号空间 f00–f55（56 个位置）数，读者会得到 64.3%；按「每角色 6 条」读才成立 100%。建议改成 `6 角色 × 6 条 = 36/36`。
2. **36 条陈述里有 3 组跨角色同源复述**（f12/f51、f02/f42/f55、f11/f44），重复 4 条，折算后独立事实不超过 32 条。这不是错误——多角色复述本身就是交叉印证——只是「36 条事实」的表述会让读者误以为各自独立。
3. **f12 的「每日 1600 人次」缺主体**。若是全院门诊量，不能作导诊解释负担的分母；若是导诊台量，则 180/1600 = 11.25% 可直接进基线。这一条影响 REQ-4 的收益口径。
